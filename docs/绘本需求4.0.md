## 1. 项目背景与目标

### 1.1 背景

本次迭代主要解决以下问题：

* 绘本创作缺乏精细化引导，用户难以精准表达创作意图
* 仅支持中文绘本，无法满足多语言需求
* 绘本生成过程中，单张图片失败会导致整本绘本失败，用户无法干预
* 生成失败后用户无法查看已生成的内容，也无法针对失败图片进行修复

### 1.2 目标

* 支持中英文双语绘本创作
* 通过标签引导用户更精准地表达创作意图（语言、年龄、页数、类型、主题）
* 重构绘本生成流程，支持实时查看生成进度和结果
* 支持失败图片的单独处理（修改提示词/重新生成）
* 新增独立的编辑绘本界面，提升编辑体验
* 优化音色配置，支持多语言音色动态切换

### 1.3 范围

* **包含：**
  * 绘本首页标签栏功能
  * 生成绘本界面重构
  * 编辑绘本界面（新增）
  * 音色配置后台化
  * 多语言支持
  * 全屏弹窗样式统一
* **不包含：**
  * 后台管理界面开发（使用现有配置功能）

## 2. 功能需求详细说明

### 2.1 绘本首页

#### 2.1.1 标签栏功能（新增）

> 在故事灵感输入框下方新增标签选择区，帮助用户更精准地定义创作需求。

* **入口**：绘本首页，故事灵感输入框底部

**标签字段**

| 字段名称 | 类型       | 必填 | 默认值        | 选项                                                                         |
| :------- | :--------- | :--- | :------------ | :--------------------------------------------------------------------------- |
| 语言     | 下拉选择框 | 是   | 中文          | 中文、英文                                                                   |
| 年龄     | 下拉选择框 | 是   | 低学段(7-8岁) | 幼儿园(3-6岁)、低学段(7-8岁)、中学段(9-10岁)、高学段(11-12岁)、初中(13-15岁) |
| 页数     | 下拉选择框 | 是   | 自动          | 自动、8页、10页、12页、16页、20页                                            |
| 类型     | 下拉选择框 | 否   | 不限          | 不限、童话故事、成长故事、科普知识、品德教育、冒险故事、历史传说             |
| 主题     | 下拉选择框 | 否   | 不限          | 不限、勇气、友情、亲情、诚实、责任、环保、自信、分享、感恩                   |

**标签用途说明**

标签参数将用于 AI 提示词，影响绘本生成效果：

| 标签 | 大纲生成阶段 | 脚本生成阶段 | 说明                                       |
| :--- | :----------- | :----------- | :----------------------------------------- |
| 语言 | ✓           | ✓           | 控制输出语言和旁白语言                     |
| 年龄 | ✓           | ✓           | 影响故事复杂度、用词难度、旁白表达方式     |
| 页数 | ✓           | -            | 控制分镜数量（"自动"时由 AI 根据情节决定） |
| 类型 | ✓           | -            | 影响故事类型和叙事风格                     |
| 主题 | ✓           | -            | 影响故事的核心寓意                         |

### 2.2 绘本阅读器

#### 2.2.1 音色配置后台化（调整）

> 将音色列表从前端写死改为后台配置，支持根据绘本语言动态显示对应音色。

* **变更说明**：
  * 之前：前端写死 4 个中文音色
  * 现在：通过后台配置 JSON，支持中英文音色列表

**后台配置格式**

配置 Key：`storybook_voice_config`

```json
{
  "zh": [
    { "name": "音色名称1", "voiceId": "zh_voice_id_1" },
    { "name": "音色名称2", "voiceId": "zh_voice_id_2" }
  ],
  "en": [
    { "name": "Voice Name 1", "voiceId": "en_voice_id_1" },
    { "name": "Voice Name 2", "voiceId": "en_voice_id_2" }
  ]
}
```

**前端逻辑**

1. 打开阅读器时，根据绘本的语言字段（zh/en）获取对应音色列表
2. 动态渲染音色下拉选项
3. 默认选中列表第一个音色

#### 2.2.2 旁白文字样式优化（调整）

> 优化阅读器右侧旁白文字的显示效果。

* **字体调整**：旁白文字字体改为楷体，提升阅读体验

#### 2.2.3 旁白文本引号处理（调整）

> 修复模型返回文本中引号格式不一致的问题。

* **问题描述**：模型返回的旁白文本中，需要使用双引号的地方返回的是单引号
* **处理方式**：将旁白文本中的单引号替换为双引号
* **实现位置**：前端或后端处理均可

### 2.3 生成绘本界面（新增，替代原进度弹窗）

> 重构绘本生成流程界面，支持实时查看生成图片、处理失败图片、继续生成等功能。

* **入口**：
  * 大纲确认界面点击"生成绘本"按钮
  * 我的绘本页点击"生成中"状态的绘本卡片
  * 我的绘本页点击"已取消/生成失败"且脚本已生成的绘本卡片

#### 2.3.1 生成步骤

界面分为四个步骤：

| 步骤 | 名称     | 说明                                               |
| :--- | :------- | :------------------------------------------------- |
| 1    | 分析大纲 | 固定提示语，等待脚本生成流式输出                   |
| 2    | 生成脚本 | 根据流式输出标记实时切换提示语（同原进度弹窗逻辑） |
| 3    | 生成图片 | 显示封面+全部页的卡片，实时展示生成状态            |
| 4    | 完成     | 所有图片生成结束                                   |

* 步骤1、2的提示语内容与原进度弹窗一致，仅呈现方式调整

#### 2.3.2 生成图片阶段 - 卡片展示

**卡片内容**

| 字段     | 说明                     |
| :------- | :----------------------- |
| 页码     | 封面 / 第X页             |
| 文字     | 该页的文字内容           |
| 图片区域 | 根据生成状态显示不同内容 |

**图片状态**

| 状态   | 显示内容            |
| :----- | :------------------ |
| 生成中 | 加载动画            |
| 成功   | 实时显示生成的图片  |
| 失败   | 失败提示 + 操作按钮 |

**成功状态 - 卡片操作**

| 操作     | 说明                                                             |
| :------- | :--------------------------------------------------------------- |
| 修改文字 | 可编辑旁白文字，限制300字                                        |
| 修改图片 | 交互逻辑同绘本阅读器中的图片编辑（输入描述 → 生成 → 对比选择） |

**失败操作按钮**

| 失败原因   | 操作按钮   | 说明                               |
| :--------- | :--------- | :--------------------------------- |
| 敏感词失败 | 修改提示词 | 打开提示词编辑弹窗，修改后重新生成 |
| 其他原因   | 重新生成   | 使用原提示词重新生成               |

* 说明：后端在生图失败时会自动重试多次（包括敏感词净化尝试），界面显示的失败是后端停止重试后的最终状态

#### 2.3.3 修改提示词弹窗

> 用户可编辑生图提示词，解决敏感词导致的生成失败问题。

**展示内容**

生图提示词由以下三部分拼接而成，弹窗中拆分展示，用户可分别编辑：

| 字段 | 说明             |
| :--- | :--------------- |
| 角色 | 角色描述内容     |
| 场景 | 场景描述内容     |
| 画面 | 画面动作描述内容 |

* 风格提示词由系统自动拼接，不对用户开放编辑

#### 2.3.4 流程逻辑调整

**失败处理逻辑**

| 项目     | 旧逻辑                   | 新逻辑                                       |
| :------- | :----------------------- | :------------------------------------------- |
| 单张失败 | 绘本立即标记为"生成失败" | 不影响其他图片生成，全部结束后再判定绘本状态 |

**取消处理逻辑**

* 用户点击"取消生成"后，未进行的生图任务停止（算作失败），绘本标记为"已取消"
* 已取消的绘本中可能存在：已完成的图片、失败的图片

**继续生成逻辑**

* 生成失败/已取消的绘本支持继续生成
* 用户可在卡片上单独处理失败的图片（修改提示词/重新生成）

#### 2.3.5 右上角按钮

| 状态                           | 按钮                |
| :----------------------------- | :------------------ |
| 步骤1、2（分析大纲、生成脚本） | 后台生成 + 取消生成 |
| 步骤3有图片正在生成            | 后台生成 + 取消生成 |
| 全部完成                       | 去阅读 + 关闭       |
| 无生成中                       | 关闭                |

**取消生成二次确认**

| 项目   | 内容                                           |
| :----- | :--------------------------------------------- |
| 提示语 | 确定要取消生成吗？当前进度会保留，可随时继续。 |
| 按钮   | 继续生成 / 停止生成                            |
| Toast  | 已取消生成                                     |

### 2.4 我的绘本页

#### 2.4.1 绘本卡片入口逻辑（调整）

> 根据绘本状态和脚本生成情况，点击卡片进入不同界面。

| 绘本状态 | 脚本是否已生成 | 点击后打开                         |
| :------- | :------------- | :--------------------------------- |
| 已完成   | -              | 绘本阅读器                         |
| 大纲确认 | -              | 大纲确认界面                       |
| 生成中   | -              | 生成绘本界面，定位到当前步骤       |
| 生成失败 | 是             | 生成绘本界面，定位到"生成图片"步骤 |
| 生成失败 | 否             | 大纲确认界面                       |
| 已取消   | 是             | 生成绘本界面，定位到"生成图片"步骤 |
| 已取消   | 否             | 大纲确认界面                       |

#### 2.4.2 绘本卡片操作按钮（调整）

> 简化卡片操作，引导用户通过点击卡片进入详情界面操作。

* **变更说明**：
  * 已取消、生成失败的绘本卡片，移除"重新生成"按钮
  * 已完成的绘本卡片，操作菜单新增"编辑"选项，点击打开编辑绘本窗口

### 2.5 编辑绘本界面（新增）

> 新增独立的编辑绘本弹窗，替代原阅读器内的编辑模式，提供更好的编辑体验。

* **入口**：
  * 我的绘本页 → 已完成绘本 → 操作菜单"编辑"
  * 绘本阅读器 → 点击"编辑"按钮

#### 2.5.1 界面内容

* 内容与"生成绘本界面 - 生成图片步骤"一致
* 区别：没有失败项，全部为已完成状态
* 支持每一页的图片和文字修改

#### 2.5.2 卡片操作

| 操作     | 说明                                                             |
| :------- | :--------------------------------------------------------------- |
| 修改文字 | 可编辑旁白文字，限制300字                                        |
| 修改图片 | 交互逻辑同绘本阅读器中的图片编辑（输入描述 → 生成 → 对比选择） |

#### 2.5.3 与阅读器的联动

* 从阅读器打开编辑窗口时，阅读器保持打开状态
* 关闭编辑窗口后，阅读器内容自动刷新更新

#### 2.5.4 原阅读器编辑模式（移除）

* 阅读器中保留"编辑"按钮，但移除原有的编辑模式逻辑
* 点击"编辑"按钮改为打开编辑绘本窗口

#### 2.6.1 全屏弹窗关闭按钮位置统一（调整）

> 统一全屏弹窗的关闭按钮位置和样式，提升交互一致性。

  * 编辑绘本界面（新增）
* **样式要求**：以上窗口关闭按钮样式保持一致
